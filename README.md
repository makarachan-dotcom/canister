# Canister

Public-link media saver for YouTube, TikTok, Instagram, X, Facebook, and more.

## Deploy on Vercel

1. Open [Vercel](https://vercel.com/new) and import this repository.
2. Framework preset can stay empty. The build writes `.vercel/output`.
3. Build command: `npm run build`
4. No environment variables are required.
5. Deploy.

Paste a public link, watch it on step 3, then save the file.
